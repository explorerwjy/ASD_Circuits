# GENCIC

**Genetics and Expression iNtegration with Connectome to Infer affected Circuits**

GENCIC integrates de novo mutations from autism cohorts with brain-wide spatial
transcriptomics and the mesoscale mouse connectome to identify brain structures,
cell types and circuits preferentially targeted by autism-associated mutations.

## Status

The code release accompanying the preprint is being prepared and will be published
in this repository shortly. It will include the analysis code needed to reproduce
the figures and tables in the paper, with the derived data required for exact
reproduction deposited separately and linked here.
