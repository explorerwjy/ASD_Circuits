# External Data Sources

This document describes the external data required to reproduce results from scratch.
Pre-computed intermediate files are included in the data distribution; these instructions
are for regenerating them.

## Allen Brain Cell Atlas (MERFISH)

**Source**: [Allen Brain Cell Atlas](https://portal.brain-map.org/atlases-and-data/bkp/abc-atlas)

**Required for**: `scripts/build_merfish_annotation.py`, `scripts/build_merfish_umi_matrices.py`

### MERFISH Cell Metadata (Zhuang Lab)

Download ABCA-1 through ABCA-4 cell metadata and CCF coordinates:

```
MERFISH_ZhuangLab/
├── ABCA-1/
│   ├── cell_metadata_with_cluster_annotation.csv
│   └── ccf_coordinates.csv
├── ABCA-2/
│   ├── cell_metadata_with_cluster_annotation.csv
│   └── ccf_coordinates.csv
├── ABCA-3/
│   ├── cell_metadata_with_cluster_annotation.csv
│   └── ccf_coordinates.csv
└── ABCA-4/
    ├── cell_metadata_with_cluster_annotation.csv
    └── ccf_coordinates.csv
```

Access via [ABC Atlas Access](https://alleninstitute.github.io/abc_atlas_access/descriptions/MERFISH-C57BL6J-638850.html)
or `pip install abc_atlas_access`.

### Allen CCF v3 Parcellation

Download CCF-2020 parcellation metadata:

```
Allen-CCF-2020/views/
├── parcellation_to_parcellation_term_membership_acronym.csv
└── parcellation_to_parcellation_term_membership_color.csv
```

Available from [Allen CCF downloads](https://download.alleninstitute.org/informatics-archive/current-release/mouse_ccf/).

### Cluster Gene Expression (10x Whole Brain)

For regenerating `dat/SC_UMI_Mats/cluster_MeanLogUMI.csv` (cluster-level log2(UMI+1) expression):

Download per-cluster UMI count files from Allen Brain Cell Atlas (5,312 clusters, ~15 GB total).
Then run:
```bash
python scripts/build_celltype_z2_matrix.py --stage1
```

## Allen Mouse Brain ISH Atlas

**Source**: [Allen Mouse Brain Atlas](https://mouse.brain-map.org/)

**Required for**: Structure-level expression matrices, expression matching

### ISH Expression Data

Raw ISH expression energy data (213 brain structures × ~20,000 genes) is downloaded
and processed by `notebooks_mouse_str/01.Download_ISH_data.ipynb`.

The preprocessed matrix is at `dat/allen-mouse-exp/Jon_ExpMat.log2.qn.csv` (Jon's R-based
log2+QN pipeline, THE input for Z2 computation).

### ISH Expression Match Files

Pre-computed match files (17,189 files in `dat/allen-mouse-exp/ExpMatch/`) map each gene
to 10,000 expression-matched genes sampled with replacement from a ±5% quantile window.

Can be regenerated from `dat/allen-mouse-exp/ExpMatchFeatures.csv` using:
```bash
python scripts/archive/match_genes.py
```

## Allen Mouse Brain Connectivity Atlas

**Source**: [Oh et al. 2014, Nature](https://doi.org/10.1038/nature13186)

Connectivity data (weight matrix and information-theoretic scoring matrices) in
`dat/allen-mouse-conn/ConnectomeScoringMat/`. Generated by
`notebooks_mouse_str/03.Preprocessing_Connectivity_data.ipynb` from:
- Oh et al. supplementary data (nature13186-s4.xlsx)
- Allen Mouse Connectivity Cache API

## Mutation Rate Data

De novo mutation rate table: `MutationRate_20170710_rate.CorrectSymbol.txt`

Used for mutability-weighted null simulations. Referenced in config as `Denovo_mut_rate`.
